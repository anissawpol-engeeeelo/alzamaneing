# Alzamane Wings Academy Privé

Site vitrine en français, réalisé en HTML, CSS et JavaScript sans compilation ni dépendances à installer.

## Ouvrir le site

Ouvrir `index.html` dans un navigateur. Pour un serveur local, depuis ce dossier :

```sh
python -m http.server 8080
```

Puis ouvrir http://localhost:8080.

## Fichiers

- `index.html` : accueil, domaines, approche, FAQ et adresse.
- `privacy.html` : confidentialité et mentions légales séparées.
- `styles.css` : design adaptatif et animations avec prise en charge des mouvements réduits.
- `script.js` : menu mobile, animations au défilement et année du pied de page.
- `assets/logo.svg` : logo vectoriel original, ailes et étoile/boussole.

Les photographies d’illustration sont servies par Unsplash et les polices de l’accueil par Google Fonts. Une connexion internet est nécessaire pour ces ressources ; les polices système prennent le relais en leur absence.

Avant mise en ligne, compléter les informations d’hébergement sur la page de confidentialité et valider les informations de l’établissement. Aucune adresse e-mail, aucun téléphone, cursus, agrément, témoignage ou tarif n’a été inventé. Le lien Maps lance une recherche et ne constitue pas une position vérifiée. Aucun formulaire ni service de collecte de données n’est configuré.
